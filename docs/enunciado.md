# PROJECTE BUDGET: PRESSUPOSTOS DE SERVEIS DIGITALS

Benvinguda/o al **Kickoff del projecte Budget**! Aquest és l’inici d’un repte realista i apassionant: desenvolupar una aplicació que ajudi a gestionar pressupostos de forma senzilla, intuïtiva i efectiva.

## Què trobareu en aquest document?

Aquí trobareu tota la informació necessària per començar i completar el vostre projecte:

- Requisits funcionals i tècnics
- Documentació de referència
- Lliurables esperats
- Objectius pedagògics
- Rúbrica d’avaluació
- Minimum Viable Product (MVP)

Aquest projecte simula un entorn laboral real:

- Documentació predefinida (amb llacunes reals!)
- Expectatives de qualitat professional
- Comunicació amb el client (sí, hauràs de validar idees)
- Iteració contínua i decisions tècniques pròpies

La teva tasca no és només **"programar pantalles"**, sinó transformar requisits reals en solucions tècniques viables.

## Requisits tècnics

- Desenvolupament com a **SPA (Single Page Application)**
- Framework principal: **React o Angular**
- Enfocament **mobile first** amb almenys 2 punts de ruptura
- Proposta de millores al disseny i l’experiència d’usuari (**UX/UI**)
- Dades i textos configurables via fitxer **JSON** o base de dades senzilla
- Generació d’**ID únic** per a cada pressupost
- Ús de **Git i GitHub** amb model de branca **Git Flow**
- Estructura semàntica i accessible
- Testing unitari obligatori, amb escenaris escrits en **Gherkin**
- Desplegament a **Netlify, Vercel o GitHub Pages**

## Requisits funcionals pactats

Les funcionalitats mínimes esperades per al **MVP** s’organitzen en quatre grans blocs:

### Nivell 1

#### Èpica 1: Creació personalitzada de pressupostos

El sistema calcula de manera dinàmica i desglossada el preu total en funció d’un o més serveis digitals seleccionats (**SEO, Publicitat, Web**) i de la seva configuració —en el cas del servei **“Web”**, amb opcions com el nombre de pàgines i idiomes.

#### Èpica 2: Generació del pressupost

El sistema permet recollir les dades bàsiques del client per crear el pressupost amb els detalls en una vista única.

### Nivell 2

#### Èpica 3: Consulta d’històric

El sistema permet guardar, visualitzar, cercar i filtrar l'històric de pressupostos a partir d'un llistat amb enllaç al detall de cada pressupost generat.

### Nivell 3

#### Èpica 4: Compartició del pressupost

Cada pressupost es pot compartir mitjançant una **URL única** amb tota la informació detallada.

**Bonus:** exportació a PDF.

Aquesta informació es pot ampliar al **Briefing (Annex 1)** i als **mockups** per veure què implica cada funcionalitat amb la documentació annexa.

## Recursos

### Documentació de suport

Teniu accés a una documentació completa que us orientarà com si estiguéssiu en un equip professional:

- **Briefing funcional i tècnic** – Objectiu global del projecte (Annex 1)
- **Mockups** – Visualització de pantalles (Annex 2)
- **MVP** – El que és més prioritari desenvolupar per pilotar el projecte

### Recomanacions d’ús

- Prioritzeu funcionalitats clau que responen al core del projecte.
- Construeix els **user journeys** per entendre les necessitats de cada rol d'usuari.
- Escriu les **històries d'usuari** per definir l'abast tècnic de cada funcionalitat.
- Defineix i organitza les tasques en el teu **tauler Kanban** a partir del backlog.
- Consulta els **wireframes i prototips** per assegurar-te que la teva maquetació respecta la proposta de disseny (UX/UI).
- Comproveu el codi amb testos i iteracions curtes.
- Planifica iteracions curtes i utilitza el feedback de revisió (**P2P o del formador**) per millorar contínuament.
